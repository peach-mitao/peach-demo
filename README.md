# Peach 演示站

Peach 的在线体验入口，复用应用前端，通过录制数据展示馆藏浏览、搜索、资料页、播放和配置。演示包含云盘、下载渠道及任务示例；操作只在当前页面生效，刷新后恢复，不连接真实账本。

[打开演示站](https://demo.peach.video/) · [访问官网](https://peach.video/)
