# Peach 演示站

使用普通电影演示资料，在浏览器中体验 Peach 界面。

[在线演示](https://demo.peach.video/) · [官网](https://peach.video/) · [下载 Peach](https://github.com/peach-mitao/peach/releases) · [English](README.md)

[![CI](https://img.shields.io/github/actions/workflow/status/peach-mitao/peach-demo/check.yml?branch=main&label=CI&logo=githubactions&logoColor=white)](https://github.com/peach-mitao/peach-demo/actions/workflows/check.yml)
[![License](https://img.shields.io/badge/license-AGPL--3.0--only-blue?logo=gnu&logoColor=white)](LICENSE)

## 功能

- **馆藏浏览**：体验搜索、筛选、人物与影片详情页。
- **界面预览**：使用示例资料查看配置、云盘和下载任务。
- **播放器控件**：展示播放器界面；点击播放仅提示演示，不加载视频。
- **页面内状态**：操作只在当前页面生效，刷新后恢复，不连接自己的 Peach 馆藏。

影片与人物图片的来源和许可见[素材说明](https://demo.peach.video/film-sources/)。
